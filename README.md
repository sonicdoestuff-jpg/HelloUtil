**HelloUtil** is a Python utility project

## Features

- Git repository cloning
- Chatbot prototype
- Command-line interface
- ASCII startup banner

## Installation

```bash
git clone https://github.com/sonicdoestuff-jpg/HelloUtil
cd HelloUtil
```

## Usage

```bash
python main.py
```

## Menu

- `1` Git clone a repository
- `2` Chatbot
- `3` About
- `0` Exit
